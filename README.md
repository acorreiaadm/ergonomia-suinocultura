# 🌾 Plataforma Web de Ergonomia para Suinocultura

Plataforma web desenvolvida para otimizar e orientar a ergonomia ocupacional de trabalhadores no setor de **suinocultura**, aplicando rigorosamente as diretrizes da norma regulamentadora **NR-17** e os padrões visuais institucionais do **SENAR**.

---

## 🎯 Sobre o Projeto
Este projeto consiste num site responsivo e informativo focado na saúde, segurança e conforto ergonómico no ambiente de trabalho da suinocultura. A aplicação foi estruturada para traduzir requisitos regulatórios complexos em interfaces limpas, acessíveis e fáceis de navegar pelos utilizadores.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Front-End:** HTML5, CSS3, JavaScript (ES6+)
* **Design & Recursos Visuais:** Ícones vetoriais personalizados em formato SVG
* **Conformidade Normativa:** NR-17 (Ergonomia) e Padrões Visuais do SENAR
* **Versionamento & Deploy:** Git, GitHub e Vercel

---

## 📐 Diretrizes e Requisitos de Negócio
Diferente de aplicações genéricas para o setor agrícola, este sistema foi especificamente modelado para atender às particularidades operacionais da suinocultura:
1. **Foco no Setor Específico:** Direcionamento exclusivo para as rotinas e posturas de trabalho na suinocultura.
2. **Conformidade com a NR-17:** Adaptação das condições de trabalho àspetos psicofisiológicos dos trabalhadores (transporte de cargas, mobiliário, posturas e organização do trabalho).
3. **Identidade Visual SENAR:** Aplicação de diretrizes estéticas e de usabilidade alinhadas aos padrões visuais da instituição.

---

## ✨ Funcionalidades Principais
* Interface web totalmente responsiva otimizada para múltiplos dispositivos.
* Navegação intuitiva baseada em módulos de boas práticas ergonómicas.
* Utilização de ícones SVG escaláveis para melhor desempenho visual e leveza da página.
